# Core migration evidence

DGP Core preserves the complete framework-neutral product-engine behavior of the legacy Digital Service Engine while accepting canonical DGP v1 definitions. Internal restructuring is welcome, but a smaller implementation is an optimized replacement only when downstream outcomes are covered by equivalent tests. The current implementation is a partial slice until this ledger is satisfied.

| Legacy behavior | Legacy evidence | Destination | Preserved outcome | Implementation status | Tests/evidence | Explicit approval |
| --- | --- | --- | --- | --- | --- | --- |

| Canonical authoring normalization | `src/core/normalise.ts`; normalization tests | DGP Core, consumed by Workspace authoring | Preserve canonical defaults, root/filter invariants, binding normalization, deduplication, recursive options, notices, fallbacks, effects, validation declarations, and deterministic collection shapes without legacy aliases. | **Pending migration**; isolated capability resolution is not a full normalizer | Classify and replace every normalizer test; external invalid-definition tests remain in Validation | Legacy compatibility removed; canonical behavior preserved |
